# Demo script (about 4 minutes)

Setup: `npm run dev`, open http://localhost:3000, click **Reset demo data** on the dashboard (confirm). Role dropdown (bottom of sidebar) starts as Brand Manager. All data is fictional.

1. **Problem (20 s).** "Facts change but published content does not, and guidelines are read differently by different people. Inkloom checks content against approved facts and approved rules, explains every finding, and a human decides."
2. **Sample brand (20 s).** Open **Brand Knowledge Base**: Battery life 40 hours (with evidence), Warranty 2 years (with evidence), Water resistance IP68 (**Evidence required**, none registered).
3. **Bad ad (30 s).** **Content Checker → Load sample problem ad → Check Content.** 8 findings: `48 hours` and `3-year` conflict with facts (evidence shown), `guaranteed best` / `100% risk-free` prohibited, `!!!` style, `IP68` "Evidence required", `long-lasting` / `rugged` need human review.
4. **Evidence (20 s).** On the `48 hours` card: approved fact link (v1), evidence DOC-NOVA-SPEC-001, "Exact match". Point out the IP68 card says missing evidence is not proof of falsehood.
5. **Correct and recheck (30 s).** Click **Accept** on each suggested fix (switch role to Creator first to show the Approve button is disabled for creators). **Recheck**: 40 hours and 2-year now Supported; three items still need a human. Original text is kept under **Version history**.
6. **Approve (20 s).** Role → Reviewer. Approve without a comment is refused (3 unresolved items); add "IP68 certificate pending; vague claims accepted by me" → Approved. Note the banner: AI is advisory; nothing is published.
7. **Fact change (50 s).** Role → Brand Manager. **Knowledge Base → Battery life → Change value → 32**, reason "Spec sheet rev B". Open **Review Queue**: "NovaPhone X launch ad" (was **approved**) and "Landing page hero" are **Outdated: re-review**; the social post is not outdated. Open the launch ad: shows "40 hours", old v1 → new v2 (32), link to the changed fact. **Recheck** shows a conflict, Accept, Recheck: impact resolves. **Claim Ledger** shows the impact records and which assets match the current value.
8. **Calibration + audit (40 s).** **Guideline Calibration:** draft rule "Tone should be approachable" is marked *Needs human review* and not enforced; in the tester, run sample text before/after approving a draft rule. **Audit History:** fact change, approvals, rule decisions with actor and role.
9. **Close (30 s).** Three improvements: evidence-grounded verification, claim-change impact tracking, human approval + audit trail. Open **Testing & Evaluation → Run Demo Evaluation**: 28/33 exact, with the 5 known misses shown. Say plainly: local SQLite, demo roles, 33 synthetic cases, Claude integration not yet run live, multi-reviewer calibration not built.
